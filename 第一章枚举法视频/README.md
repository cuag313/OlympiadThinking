## 题目列表

### 典型示例（3道）

1. **question_10180.mp4** - 纸币组合问题 ✅ 已生成
   - 题目：用10元、20元和50元的纸币各6张，组成60元有几种方法？
   - 答案：5种方法
   - 解题方法：分类枚举（只用一种纸币→用两种纸币→用三种纸币）

2. **question_10181.mp4** - 三角形三边枚举 ⏳ 待生成
   - 题目：将15分米木棒截成三段，能组成几种不同的三角形？
   - 答案：7种
   - 解题方法：按最长边分类枚举（7分米→6分米→5分米）

3. **question_10182.mp4** - 骰子点数概率 ⏳ 待生成
   - 题目：掷两个骰子，点数和为5-8思思获胜，其他值想想获胜，谁获胜可能性大？
   - 答案：思思获胜可能性大
   - 解题方法：表格枚举（6×6表格枚举所有36种情况）

### 思维挑战（5道）

4. **question_10183.mp4** - 三位数排列 ⏳ 待生成
   - 题目：用3、5、7三张数字卡片可以摆出哪几个三位数？
   - 答案：6个（357、375、537、573、735、753）
   - 解题方法：树状图枚举（百位→十位→个位）

5. **question_10184.mp4** - 蚂蚱跳动 ⏳ 待生成
   - 题目：蚂蚱从5厘米处跳5次到8厘米处，有几种跳动方式？
   - 答案：5种
   - 解题方法：路径枚举（数轴上展示跳动路径）

6. **question_10185.mp4** - 最大面积 ⏳ 待生成
   - 题目：80厘米铁丝围长方形，长宽都是5的倍数，哪种面积最大？
   - 答案：正方形（20×20）面积最大
   - 解题方法：表格枚举（长/宽/面积三列表格对比）

7. **question_10186.mp4** - 装错信封 ⏳ 待生成
   - 题目：4封信都装错的方法有多少种？
   - 答案：9种
   - 解题方法：逐一枚举（列出所有9种全错排列）

8. **question_10187.mp4** - 公交车座位 ⏳ 待生成
   - 题目：15个车站，每站恰好一人到以后各站，至少需要多少座位？
   - 答案：56个
   - 解题方法：递推枚举（站次/上车/下车/车内人数表格）

## 视频质量改进

本次重新生成的视频应用了以下改进：

1. **渲染质量提升**：从480p/15fps提升到1080p/60fps，画面更清晰流畅
2. **动画效果优化**：使用FadeIn替代Write动画，避免中文笔画"拉花"现象
3. **行距增加**：相邻元素间距从0.2-0.3增加到0.8，避免文字重叠
4. **换行限制放宽**：每行字符数从8个增加到10个，题目显示更自然
5. **教学内容增强**：添加表格、树状图、数轴、枚举图表等可视化元素

## 使用说明

每个视频文件对应一道题目，视频内容包含：
- 题目分析
- 枚举法解题思路
- **数形结合**：能用图形表示的一定用图形
- **表格枚举**：需要对比数据时使用表格
- **树状图**：需要有序枚举时使用树状图
- **路径图**：需要展示变化过程时使用数轴或路径图
- 详细解答过程
- 答案总结

建议配合教材第一章内容使用，先尝试自己解题，再观看视频讲解。
